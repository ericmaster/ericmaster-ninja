# Artifacts Manager

**GitHub:** [https://github.com/ericmaster/artifacts-manager](https://github.com/ericmaster/artifacts-manager)  
**Live / Local:** Node.js service on port `41820` / Cloudflare Tunnel (`https://artifacts.nimblersoft.com`)

Artifacts Manager is a multi-project visualizer and management hub for interactive HTML, SVG, visual components, and Markdown artifacts generated by AI coding agents across local workspaces.

## Key Features

- **Centralized Project Registry:** Discovers and registers project repositories to catalog all agent-generated artifacts in one place.
- **Sandboxed Interactive Viewer:** Renders interactive deliverables (HTML mockups, prototypes, system diagrams, visual reports) in secure, sandboxed iframes.
- **Theme & Design System Integration:** Built with the Nimblersoft Dark Design System tokens for clean, high-contrast visualization.
- **CLI Utility (`artman`):** Simple command-line interface to register repositories and query artifacts from terminal scripts or agent workflows.
- **Agent Skill Integration:** Shipped alongside the `with-artifact` agent skill for streamlined artifact authoring.

## CLI Usage

```bash
# Register a repository with the hub
./bin/artman register /path/to/project

# List registered projects and cataloged artifacts
./bin/artman list
```

## Stack

- **Frontend & App Framework:** SvelteKit 5 + Svelte 5
- **Runtime & Adapter:** Node.js (`@sveltejs/adapter-node`)
- **Styling:** CSS variables & design tokens (Nimblersoft Dark / Agentic Theme)
- **Storage:** Local JSON registry & filesystem manifest scanning
