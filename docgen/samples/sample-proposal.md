Thank you for the opportunity to propose a DataOps and LLMOps advisory
engagement. This Statement of Work ("SOW") outlines the scope, deliverables,
timeline, and fees for the engagement described below.

## 1. Scope of Work

- Audit the existing data pipeline and model-serving infrastructure.
- Recommend an MLOps toolchain aligned with the client's cloud provider.
- Stand up CI/CD for model training and deployment.
- Document runbooks for on-call handoff.

## 2. Deliverables

1. Current-state architecture assessment (written report).
2. Target-state architecture proposal, with a phased migration plan.
3. A reference CI/CD pipeline, deployed to a staging environment.
4. Two half-day knowledge-transfer sessions with the client's engineering team.

## 3. Timeline

| Phase                  | Duration | Output                       |
| ----------------------- | -------- | ----------------------------- |
| Discovery & assessment  | 1 week   | Current-state report          |
| Architecture design     | 1 week   | Target-state proposal         |
| Implementation          | 3 weeks  | Reference pipeline in staging |
| Knowledge transfer      | 1 week   | Runbooks, handoff sessions    |
